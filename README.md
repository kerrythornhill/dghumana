# DG Humana — Common Horizon

A restrained purpose-and-vision website for DG Humana Institute: human dignity and agency in the age of automation.

The single page presents purpose, vision, and direction. It makes no claims about a research staff, funding, tax status, or completed programs.

`content/` contains editable HTML. `theme/` is a classic WordPress theme. `preview/` renders the same content without WordPress.

```sh
python tools/build.py
```

Open `review.html` for a self-contained preview with desktop, tablet, and phone width controls. It embeds the artwork and fonts. Alternatively, open `preview/index.html` or serve the repository with a local static HTTP server. The site requires no JavaScript; only the standalone review controls use it.

## Design

Muted indigo, porcelain, mist teal, and soft warmth. A luminous book illustration gives visual form to inquiry and possibility. Typography and spacing connect this site to Kerry Thornhill’s personal website while retaining an independent identity.
